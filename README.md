# PINCELADAS VIRTUAIS: GENERATIVE MIRROR IN P5.JS

##  Project Description
This is an interactive artistic project that explores the deconstruction of digital imagery through algorithmic painting. The program transforms static photographs and real-time video feed (Webcam) into fluid compositions, utilizing Perlin noise to simulate the organic behavior of brushstrokes.

**Live Project:** [Try it on p5.js Web Editor](https://editor.p5js.org/SaraAndrade/full/lVGQwFCsD)

---

##  How to Use & Navigate

1. **Change Art:** Click the **"NEXT"** button (bottom right corner) to advance between slides.
2. **Paint with the Mouse:** On image slides (1, 2, and 3), click and drag the mouse across the screen to paint over the canvas.
3. **Upload Images (Slide 4):** Drag and drop an image file (`.jpg` or `.png`) from your computer directly into the designated rectangle.
4. **Save Artwork:** Press the **"S"** or **"s"** key on your keyboard to save a snapshot of your current painting as an image.

---

##  Technical Concepts Used

* **p5.js:** Main library used for creating computational art.
* **Perlin Noise (`noise`):** Used to create deformed and fluid shapes that mimic real ink splatters, replacing standard `random()` which would generate completely random and disproportionate values.
* **Pixel Manipulation:** Extraction of color and brightness from the original image to define the color and size of each brushstroke.
* **Advanced Interactivity:** Drag & drop system for image uploading and real-time webcam video capture.
